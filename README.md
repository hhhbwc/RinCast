# RinCast

> [!IMPORTANT]
> **项目独立迁移与重构公告 / Project Relocation Announcement**
>
> 本仓库最初作为 [TheReal-Flo/RinCast](https://github.com/TheReal-Flo/RinCast) 的优化 Fork 进行开发。随着对视频传输层、SteamVR 驱动管线、跨品牌 OpenXR 运行时等等的深入改造，累计变更已超过 150+ 个文件、35,000+ 行代码。
>
> 如此庞大且涉及底层协议与架构的改动，已远远超出了向原项目提交 PR 的合理范畴。本项目已正式转为单独的开源项目进行维护。
